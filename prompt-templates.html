🤖 Sådan får du det bedste ud af Claude Code

Prompt-skabeloner til den agenterede CLI – kopiér, tilpas og kør.

Claude Code er et fantastisk værktøj, fordi det ikke bare er en passiv chatbot – det er en agenteret CLI (Command Line Interface), der har direkte adgang til dit filsystem, din terminal og dine testværktøjer.

For at få det absolut bedste ud af Claude Code, skal du give den en prompt, der udnytter dens evne til at skrive kode, køre test, læse fejlmeddelelser og rette sig selv, indtil opgaven er løst.

Her er en række stærke prompt-skabeloner, du kan kopiere og tilpasse alt efter, hvad du vil have den til.

Skabelon 1

Udvikling af en ny funktion (Test-Driven)

Dette er den absolut bedste måde at bruge Claude Code på. Du beder den om at bygge noget, men tvinger den til at verificere, at det rent faktisk virker, før den erklærer sig færdig.

Prompt: "I need you to implement a new feature: [Beskriv funktionen, f.eks. 'a user authentication middleware using JWT']. Please follow these steps: 1. Scan the repository to understand the current architecture and style. 2. Create or update the necessary files to implement the feature. 3. Write comprehensive unit tests for this feature. 4. Run the test suite using our test command (e.g., npm test or pytest). 5. If any tests fail, analyze the logs, fix the code, and rerun the tests until everything passes perfectly. Do not ask me for permission between steps; act autonomously until the tests pass."
Skabelon 2

Fejlsøgning og bug-fixing

Hvis du har en irriterende fejl i din kode, kan du lade Claude Code lege detektiv i din terminal.

Prompt: "There is a bug in the application where [Beskriv fejlen, f.eks. 'the total price in the shopping cart is calculated incorrectly when a discount code is applied']. Task: 1. Find the files responsible for this logic. 2. Run the application or specific tests to reproduce the bug if possible. 3. Fix the bug while ensuring you don't break existing functionality. 4. Run the full test suite to confirm the fix works and nothing else is broken. 5. Show me a summary of what the issue was and how you fixed it."
Skabelon 3

Refactoring og kode-optimering

Hvis du har noget "legacy" kode eller noget rod, der trænger til en kærlig hånd, kan du bruge denne.

Prompt: "I want to refactor the file [Indsæt filnavn, f.eks. src/services/payment.js]. Goals: • Improve readability and reduce complexity (break down large functions if necessary). • Ensure proper error handling and logging. • Maintain 100% backward compatibility. Before you make changes, run the existing tests to ensure they work. After refactoring, run the tests again to prove that nothing broke. If we lack test coverage for this file, write the tests first before refactoring."

Hvorfor virker disse prompter så godt?

  • De giver autonomi. Claude Code er designet til at køre kommandoer for dig. Ved at sige "act autonomously" slipper du for, at den spørger om lov for hvert lille skridt.
  • De inkluderer et feedback loop. Ved at tvinge den til at køre dine test-scripts (npm test, pytest, cargo test osv.), opdager den selv sine fejl og retter dem, før du overhovedet ser koden.
